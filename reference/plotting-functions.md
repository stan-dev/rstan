# RStan Plotting Functions

List of RStan plotting functions that return ggplot objects

## RStan plotting functions

- Posterior intervals and point estimates:

  [`stan_plot`](https://mc-stan.org/rstan/reference/stan_plot.md)

- Traceplots:

  [`stan_trace`](https://mc-stan.org/rstan/reference/stan_plot.md)

- Histograms:

  [`stan_hist`](https://mc-stan.org/rstan/reference/stan_plot.md)

- Kernel density estimates:

  [`stan_dens`](https://mc-stan.org/rstan/reference/stan_plot.md)

- Scatterplots:

  [`stan_scat`](https://mc-stan.org/rstan/reference/stan_plot.md)

- Diagnostics for Hamiltonian Monte Carlo and the No-U-Turn Sampler:

  [`stan_diag`](https://mc-stan.org/rstan/reference/stan_plot_diagnostics.md)

- Rhat:

  [`stan_rhat`](https://mc-stan.org/rstan/reference/stan_plot_diagnostics.md)

- Ratio of effective sample size to total posterior sample size:

  [`stan_ess`](https://mc-stan.org/rstan/reference/stan_plot_diagnostics.md)

- Ratio of Monte Carlo standard error to posterior standard deviation:

  [`stan_mcse`](https://mc-stan.org/rstan/reference/stan_plot_diagnostics.md)

- Autocorrelation:

  [`stan_plot`](https://mc-stan.org/rstan/reference/stan_plot.md)
